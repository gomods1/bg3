# Test saves

Saves made while testing the mod, so you can jump straight to a place or situation instead of
playing up to it. They are on the [test-saves release](https://github.com/gomods1/bg3/releases/tag/test-saves),
one zip per save. Game build 4.1.1.7398727 (Patch 8 hotfix 9), Script Extender v32, game in Spanish.

To use one: unzip it, and copy the folder inside (named like `Tav-...__QuickSave_4`) into
`%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\PlayerProfiles\Public\Savegames\Story\`,
then load it from the game's Load menu. `python tools/game.py restore <NN>` does the same for
developers with the saves in `saves/`.
